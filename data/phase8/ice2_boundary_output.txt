4)  Can the even branch be unavailable forever?  YES, but only on a thin family.
    p_{k+1} = a_{k+1} p_k + p_{k-1} with p_0 = 0, p_1 = 1.  So p_2 = a_2, and once
    (p_{k-1},p_k) = (1,1) the next is odd iff a_{k+1} is even.  Hence
        p_k odd for every k >= 1   <=>   a_2 odd and a_k even for all k >= 3.
    (Note p_2 = a_2, so an all-even digit string fails immediately: p_2 is even.)
    digit string              p_k odd for all k<=25?   predicted
    a_2 odd then all even     True                     True
    all digits even           False                    False
    a_2 odd, one odd later    False                    False
    a_k = k                   False                    False
    So at intercept 0 the even branch CAN be unavailable at every scale -- exactly the
    single bad cycle the Phase 3 automaton found.  At a general intercept the y-roots
    have weight p_k - c_k p_{k-1}, so an odd c_k with p_{k-1} odd flips the parity:
    general intercepts have strictly more even-weight opportunities than intercept 0.

4b) The quantitative route: an EXACT identity for the odd-branch surplus driver.
    For EVERY k and EVERY admissible (c_k), bounded type or not, the y-witness has
        ell_k = q_{k-1}(lam_{k-1} + d_k),   E_k = y(k) - 2 = lam_{k-1}(m_{k-1}-1)/(lam_{k-1}+d_k),
    so the root length and the denominator cancel EXACTLY:
        ell_k * E_k = q_{k-1} lam_{k-1} (m_{k-1} - 1) = q_{k-2} * (m_{k-1} - 1).
    On a keep-one tail (d_{k-1} = 1) this is q_{k-2} lam_{k-2} m_{k-2} = q_{k-3} m_{k-2}.
    Since m_{k-2} >= 1 this is >= q_{k-3} -> infinity, EVEN WHEN E_k -> 0.  The odd
    branch therefore survives ice = 2 provided  q_{k-3} m_{k-2}  beats the penalties
    ceil(D(R_k)) log2 3 + log2(2 ell_k).  Measured:
