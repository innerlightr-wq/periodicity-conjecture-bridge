(J) The EXCEPTIONAL case is a finite shift of the rho = 0 word.  rho = j0 - m0*alpha gives
    {n alpha + rho} = {(n - m0) alpha}, so s_n = t_{n-m0} with t the rho=0 coding.  Since
    Phi(sigma s) = T(Phi(s)) and T maps Q_odd bijectively onto the relevant rationals both ways,
    rationality of Phi is shift-invariant -- so the case reduces to Phase 12's rho=0 theorem.
    s_n == t_(n-5) for 5 <= n < 600 : True
