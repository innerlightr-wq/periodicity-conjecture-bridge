(a) Translation sign and half-open endpoints, by case analysis.
    chi = 1_[0,beta).  s_{m+ell} != s_m  iff  chi({m a + r}) != chi({m a + r + ell*a}),
    and {x + ell*a} = {x + delta} with delta := ell*a - round(ell*a).  For delta > 0:
      x in [0, beta-delta) : x+d in [delta, beta)        both 1   -> match
      x in [beta-delta, beta): x+d in [beta, beta+delta)  1 vs 0  -> MISMATCH
      x in [beta, 1-delta)  : x+d in [beta+delta, 1)     both 0   -> match
      x in [1-delta, 1)     : {x+d} in [0, delta)         0 vs 1  -> MISMATCH
    so M(delta) = [beta-delta, beta) u [1-delta, 1).  For delta < 0, e := -delta:
      x in [0, e)           : {x-e} in [1-e, 1)           1 vs 0  -> MISMATCH
      x in [e, beta)        : x-e in [0, beta-e)          both 1  -> match
      x in [beta, beta+e)   : x-e in [beta-e, beta)       0 vs 1  -> MISMATCH
      x in [beta+e, 1)      : x-e in [beta, 1-e)          both 0  -> match
    so M(-e) = [0, e) u [beta, beta+e).  The half-open side of each arc MATCHES the
    half-open side of the partition -- an endpoint slip here would move m* by one.
