==============================================================================
    T1 and T2 are QUALITATIVE (see module docstring: a limiting argument and an
    accumulation-point argument respectively).  Neither bounds H.  The bridge gives
        H >= 2^{S_n},   S_n = L_n - log2 F(W_n),
    for ANY hypothetical Phi(s) = u/v with H = max(|u|,v).  Explicit floors:

PHASE 10 / item 4.  Explicit proof of the finite-scale bounds at critical density
==============================================================================
    Let s be the coding of the rotation by alpha (bounded partial quotients, sup a_i = A)
    against [0, beta), any intercept rho.  Write k_N = #{m < N : {m alpha + rho} in [0,beta)}.

    DRIFT.  #{m<N : {m alpha + rho} in I} = #{m<N : {m alpha} in I - rho}, so the deviation
    for interval I at shift rho equals the deviation for the shifted interval I - rho at
    shift 0.  The EXTREME discrepancy D_N of ({m alpha}) bounds every interval at once and
    satisfies N D_N <= 2 N D*_N = O(sum_{i<=k} a_i) = O_A(log N)  (Kuipers-Niederreiter,
    Uniform Distribution of Sequences, Ch. 2 Thm 3.4, via the Ostrowski expansion).  Hence
        | k_N - N*beta |  =  O_A(log N),   UNIFORMLY in rho and in the interval.
    In the normalisation that actually appears in the height bound,
        k_N log2(3) - N  =  log2(3) * (k_N - N*beta)  =  O_A(log N),
    using beta*log2(3) = 1 exactly.

    ROOT DISCREPANCY.  D(W) = max_i |k_i - i*k_ell/ell| <= max_i |k_i - i*beta| +
    max_i i*|beta - k_ell/ell| <= O_A(log ell) + |k_ell - ell*beta| = O_A(log ell).
