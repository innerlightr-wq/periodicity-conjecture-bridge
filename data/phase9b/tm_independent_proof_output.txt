2.3  The arithmetic contradiction, for EVERY hypothetical rational value.
     Suppose Phi(t) = u/v in lowest terms; since Phi(t) in Z_2, v is odd.  Put
     H := max(|u|, v), a FIXED finite integer once u/v is chosen.  For each m set
         M_m := u*delta_m - v*c_{W_m}  =  v*delta_m*(Phi(t) - Phi(W_m^inf)).
     * delta_m != 0 (2^ell = 3^k forces ell = k = 0);  delta_m is odd.
     * M_m != 0, because Phi is injective and t != W_m^inf (step 1.6).
     * v_2(M_m) = v_2(v delta_m) + v_2(Phi(t) - Phi(W_m^inf)) = 0 + lcp(t, W_m^inf) = L_m,
       by Prop. 2.2 and v, delta_m both odd.  Hence |M_m| >= 2^{L_m}.
     * |M_m| <= |u||delta_m| + v c_{W_m} <= H (|delta_m| + c_{W_m}) = H F(W_m).
     So 2^{L_m} <= H F(W_m), i.e.  S_m = L_m - log2 F(W_m) <= log2 H  for EVERY m.
     But S_m >= (2/3)|W_m| - log2(1 + 3|W_m|) -> +infinity.  Contradiction for every
     choice of u/v.  Therefore Phi(t) is irrational.

     Note the quantifier order: H is chosen AFTER u/v but BEFORE m, and the bound on S_m
     is uniform in m, so a single m with S_m > log2 H already refutes that u/v.
