(D) Audit of the Waldschmidt estimate (Thm 10.1) as applied.
    Form: Lambda_m = A_m log 3 - log 2, so n = 2 logarithms, alpha_1 = 3, alpha_2 = 2,
    b_1 = A_m, b_2 = -1.   D = [Q(3,2,A_m,-1):Q] = [Q(A_m):Q] = 2 for m >= 1.
    log A_1 = max(1, h(3), e|log 3|/D) = max(1, 1.098612, 1.493169) = 1.493169
    log A_2 = max(1, h(2), e|log 2|/D) = max(1, 0.693147, 0.942085) = 1.000000
    c_1 = (50n)^(3n) D^(n+2) log A_1 log A_2 = 100^6 * 2^4 * 1.493169 * 1.000000 = 2.38907e+13
    B >= (50 n D log A)^(3n) = 7.09306e+14, i.e. log B >= 34.1953

    HEIGHT CONVENTION -- the one place the Phase 13 note was loose.  Waldschmidt's hypothesis is
    log B >= h(1 : b_1 : ... : b_n) with h the ABSOLUTE LOGARITHMIC WEIL height, whereas
    H(A_m) below is the CLASSICAL height (largest |coefficient| of the primitive minimal
    polynomial).  The two are related by h(a) = (1/d) log M(P) and M(P) <= ||P||_2 <=
    sqrt(d+1) H, so for d = 2,  h(A_m) <= (log H(A_m) + log sqrt 3)/2.  Also h(-1) = 0 and
    h(1:b_1:b_2) <= h(b_1) + h(b_2).  Hence
        h(1 : A_m : -1) <= (log H(A_m))/2 + 0.275 .
    Phase 13 used log B = log H(A_m) + 2, which is LARGER, hence still admissible: both
    hypotheses on B are lower bounds, and the conclusion is monotone decreasing in B, so
    overestimating B is safe.  It is also wasteful by a factor of about 4 in the exponent;
    the sharper choice is used from here on.

    HEIGHT BOUND, proved rather than measured.  A_m = (a_m + 7m sqrt5)/14 with
    a_m = -7m + 2 - 14 j_m and |j_m| <= m+2, so |a_m| <= 21m + 30, and the (not necessarily
    primitive) minimal polynomial is 196 x^2 - 28 a_m x + (a_m^2 - 245 m^2).  For m >= 1:
        196 <= 196 m^2,   28|a_m| <= 588m + 840 <= 1428 m^2,
        |a_m^2 - 245 m^2| <= max((21m+30)^2, 245 m^2) <= 2601 m^2,
    so  H(A_m) <= 2601 m^2  for every m >= 1.
    VERIFICATION (exact integer heights):
    max H(A_m)/m^2 over 1 <= m <= 20000 : 55.00   (proved bound 2601; the bound is not tight,
     but it is proved, and a tighter measured value must not be substituted for a proof)

    CONSEQUENCE, stated plainly: C and C_0 ARE numerical for the whole family (C via A alone,
    C_0 absolutely), and c_1 is numerical once D is fixed.  But f(M) is NOT uniformly numerical
    for the family, because log B_M needs C_h and t(M) needs c_L, and neither is bounded over
    all (alpha, rho) of a given (A, D).  For any SINGLE explicit (alpha, rho) both are a finite
    computation, so f(M) is numerical case by case -- which is what was done above for the named
    example, and is not claimed for the family.

(F) Four different heights, which must not be conflated.
    1. HEIGHTS OF THE APPROXIMANTS.  Phi(W^inf) = c_W/(2^ell - 3^k) is an actual rational that
       matches s on a prefix of length L. Its height is about 2^ell. These exist, and are large,
       and prove nothing by themselves.
    2. THE HYPOTHETICAL VALUE.  The proof supposes Phi(s) = u/v with H = max(|u|,v) FIXED, then
       derives a contradiction. The quantifier order matters: H is chosen before M.
    3. PRACTICAL FINITE CERTIFICATES.  Exact integer comparisons 2^L > F(W) 2^S at computed
       witnesses: H >= 2^462, 2^838, 2^872, 2^2469, 2^15998.  No analytic input; these are the
       only numerically useful floors.
    4. THE THEORETICAL THRESHOLD.  f(M) above.  It first turns positive near M_0 = 1.78e+18, at a
       witness length of about 2^7.367e+16 -- entirely beyond computation, and worth nothing
       numerically.  Its value is that it is written down rather than merely 'effective'.
    Rows 3 and 4 answer different questions and neither improves the other.
