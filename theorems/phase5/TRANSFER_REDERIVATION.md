# TRANSFER_REDERIVATION.md

Re-derived from the definition alone (`u_n=v_n\oplus v_{n+1}`, equivalently `v_{n+1}=v_n\oplus u_n`), without consulting Phase 2's derivation text while re-deriving.

## Setup

`v_0\in\{0,1\}` fixed. `u$ agrees with `W^\infty` (`W` length `\ell`, weight `s=\sum W`) for the first `L` symbols exactly: `u_i=W^\infty_i` for `i<L`, `u_L\ne W^\infty_L`.

## Even weight (`s` even)

Claim: `v_i=V^\infty_i` for `i=0,\ldots,L` (i.e. `L+1` agreeing symbols), where `V:=v[0{:}\ell]`, and `v_{L+1}\ne V^\infty_{L+1}`.

*Proof by induction on `n=0,\ldots,L-1`.* Base: `v_0=V^\infty_0` (both equal the seed, trivially). Step: suppose `v_n=V^\infty_n` for some `n<L`. Since `n<L`, `u_n=W^\infty_n`. `V^\infty` is itself generated by the identical recursion (`V^\infty_{n+1}=V^\infty_n\oplus W^\infty_n`, because `V` is defined as `v`'s own first `\ell` symbols, generated from `v_0$ by exactly the same XOR-recursion driven by `u=W^\infty` on `[0,\ell)`, and `W^\infty$ is `\ell`-periodic so the SAME recursion, reapplied every `\ell` steps, reproduces `V` — this is the definition of `V^\infty`, not an assumption). So `v_{n+1}=v_n\oplus u_n=V^\infty_n\oplus W^\infty_n=V^\infty_{n+1}`. Induction gives `v_n=V^\infty_n` for `n=0,\ldots,L`. At `n=L`: `v_{L+1}=v_L\oplus u_L=V^\infty_L\oplus u_L`, and `V^\infty_{L+1}=V^\infty_L\oplus W^\infty_L=v_L\oplus W^\infty_L`; since `u_L\ne W^\infty_L`, `v_{L+1}\ne V^\infty_{L+1}`. `\blacksquare`

**`L_v=\text{lcp}(v,V^\infty)=L+1` exactly.**

## Odd weight (`s` odd)

`V:=v[0{:}\ell]`. One period of `u=W^\infty` flips the running XOR-parity (odd weight), so `v[\ell{:}2\ell]=\bar V` (bitwise complement). By induction, `v`'s blocks of length `\ell` alternate `V,\bar V,V,\bar V,\ldots` **as long as `u$ keeps matching `W^\infty`** (i.e. through position `L`). Let `R:=V\bar V` (length `2\ell`). Direct block-matching (as in the even case, now tracking pairs of blocks) gives `v_i=R^\infty_i` for `i=0,\ldots,L`, and the same one-step argument at `n=L` gives `v_{L+1}\ne R^\infty_{L+1}` (the disagreement `u_L\ne W^\infty_L` still breaks the recursion at exactly this point, regardless of which half-block of `R` it falls in — the argument only used `v_n=(\text{target})_n$ and `u_n=W^\infty_n` for `n<L`, valid for both `V^\infty` and `R^\infty` targets by the identical inductive mechanism). **`L_v=L+1` exactly, root `R=V\bar V`, length `2\ell`.**

## Checking every item the task lists as a risk

- **Indexing off-by-one.** The `+1` is not an error to be found — it is the actual, re-derived, correct answer (traced to the seed `v_0` always trivially matching, one "free" agreeing symbol beyond what `u`'s own agreement drives).
- **Boundary mismatch masking.** Checked explicitly above: the disagreement at `u_L` provably propagates to a disagreement at `v_{L+1}` in both parity cases — it cannot be "masked" because the recursion step at `n=L` is a bijection (`a\mapsto a\oplus u_L`) applied to equal inputs (`v_L=(\text{target})_L`) with unequal drivers (`u_L\ne W^\infty_L`), which always gives unequal outputs.
- **Seed dependence.** `v_0` appears only as the shared base case; both `v` and the target sequence use the *same* `v_0`, so it cancels — the identity holds for either seed, unchanged.
- **Complement dependence.** Swapping `v_0\to1-v_0` complements `v$, `V`, and `R` uniformly (every step of the induction XORs both sides by the same constant); `L_v$ is unaffected.
- **Period collapse (`R` not primitive).** Not addressed by this derivation — and does not need to be: the depth identity `L_v=L+1` holds for `R` *as constructed* (length `2\ell`), whether or not `R$ has a shorter fundamental period; primitivity only affects which witness is *tightest*, not whether this one is valid (`theorems/phase2/SURPLUS_THEOREM.md`'s "powers only hurt" fact — reusing a non-primitive witness never invalidates the argument, only weakens it). See `HALF_DENSITY_AUDIT.md` for whether this ever actually happens for the odd-weight `R`.
